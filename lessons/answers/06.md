# 06 answer

In `routes/console.php`:

```php
use Illuminate\Support\Facades\Schedule;

Schedule::command('device:check')->everyMinute();
```

Lifecycle: PHP job object → serialized database payload → reserved by worker → `handle()` → removed after success. Exceptions can release it for retry; exhausted attempts enter failed-job storage. A worker crash can leave a reservation until `retry_after` expires. A retry may repeat previously committed effects.

Next topics, after you can explain that flow: dispatch after database commit, unique jobs versus overlap locks, external-call timeouts, notification idempotency, chains for ordered work, batches for groups, queue retention, and worker monitoring. Redis/Horizon is an optional later backend, not required to understand these concepts.
