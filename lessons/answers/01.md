# 01 answer

Replace the exception in `DeviceCheck::run()` with:

```php
if ($device->last_seen_at === null) {
    $device->status = 'unknown';
} elseif ($device->last_seen_at->addSeconds(30)->lte(now())) {
    $device->status = 'offline';
} else {
    $device->status = 'online';
}

$device->last_checked_at = now();
$device->save();
```

`device:check-now` calls this method directly. Same process, no queue, no worker needed. The tiny check is intentionally simple; real queue use becomes valuable with slower work or independent background processing.
