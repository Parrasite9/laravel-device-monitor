# 05 answer

Inside the job class, outside methods:

```php
public int $tries = 3;
public int $backoff = 2;
public int $timeout = 10;
```

Inside `handle()`, temporarily before the check:

```php
throw new \RuntimeException('Practice failure');
```

Remove the throw after observing three attempts. Run `queue:failed`, retry its UUID, and start a fresh worker. Job-level tries takes precedence over the worker's default tries option. Worker timeouts require the PCNTL extension; do not infer timeout enforcement solely from this property on unsupported environments.
